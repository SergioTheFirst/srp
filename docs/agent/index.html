J-Space — агент

Скачать агента
  1. Распакуйте jspace-agent.zip в любую папку.
  2. Откройте install.bat в Блокноте и впишите ORG и TOKEN — их даёт администратор J-Space.
  3. Запустите install.bat от имени администратора, после установки удалите папку: в ней записан токен.
